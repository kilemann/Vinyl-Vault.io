# Vinyl Vault v1.0.0
Oversikt over vinylsamlingen: hvilke plater du eier, hvilke du mangler og hvor komplett samlingen er per artist.

Åpne: https://kilemann.github.io/Vinyl-Vault.io/

- Én fil (`index.html`), ingen backend. Alle data lagres i nettleseren (localStorage) på enheten.
- Diagrammene bruker Chart.js fra cdnjs og trenger nett. Resten virker uten.
- Ta jevnlig eksport til JSON under **Mer → Data og backup** – tømmes nettleserdata, forsvinner samlingen.

Endringer: se [CHANGELOG.md](CHANGELOG.md).
